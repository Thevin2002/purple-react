# Purple React

Personal project by **Thevin2002**, built on top of an open-source project.

## How to run

```bash
cd template/demo_1
npm install
npm start       # development server
npm run build   # production build
```

Tested: `npm install` and `npm run build` succeed on Node 24. Updated so it runs on current Node: node-sass was replaced by Dart Sass, and the start/build scripts set `--openssl-legacy-provider` (needed by react-scripts 3 on Node 17+). Missing dashboard and chat images were restored.
